# Akshay’s portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It has no package installation or build step.

## Publish with GitHub Pages

1. Create a public GitHub repository named `akshaym000.github.io`.
2. Upload the **contents of this folder** to the repository root. Keep `index.html`, `styles.css`, `script.js`, and `portfolio-data.js` together at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder, then save.
6. Once GitHub Pages finishes publishing, visit `https://akshaym000.github.io`.

Updates to the website can be published by committing the changed files to the same repository and branch.

## Edit the content

Update `portfolio-data.js` to edit the profile, focus areas, About paragraphs, social links, projects, education, interests, certificates, and writing. Layout and visual styles are in `index.html` and `styles.css`; rendering behavior is in `script.js`.

The site uses Google Fonts when a visitor is online and falls back to system fonts otherwise.
